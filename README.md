# My Week Planner

A responsive weekly time-blocking planner for students. It runs entirely in a web browser and does not require a server or account.

## Use it

Open `index.html` in Chrome, Edge, Firefox, or Safari or visit https://solsonlineadvising.github.io/Student-Weekly-Planner/ for a public version. NOTE: If you have visited the page before, it is recommended that you refresh the page on your next visit to ensure any changes, updates, or bug fixes are loaded.

## Included features

- Monday-through-Sunday schedule covering all 24 hours
- Drag across empty time to create a block
- One-minute manual time entry, including activities that continue past midnight into the next day
- Overlap prevention when adding, repeating, moving, or resizing activities
- Drag activities between days and times
- Resize activities using the handle at the bottom of each block
- Add the same activity to several days
- Color-coded categories
- Required ASU attendance selection before the weekly target is displayed
- Credit-hour workload target using six weekly hours per credit for Online students or three for On Campus students, starting at 6 credits
- Required semester selection with Summer Session A/B calculated at 7.5 hours per credit and Summer Session C at 3.75 hours per credit
- A combined School (Work/Study) category included in the live workload calculation
- Automatic browser-based saving
- CSV export and print-friendly schedule
- Responsive layout for computers and phones
- ASU-aligned digital color palette using Maroon, Gold, Rich Black, White, and limited secondary accent colors
- Deep charcoal sidebar with crisp white text, gold section labels, and elevated content panels
- Outlined category markers and a darker neutral color for Other activities
- Required category selection for every new activity

## Data and privacy

Schedule data is stored in the browser's `localStorage`. It is not transmitted anywhere. Clearing browser storage removes the saved schedule.
